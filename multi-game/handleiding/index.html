Multiplayer

Room starten, link delen, samen spelen.

In het kort

  1. Iemand start een room (host).
  2. Iedereen opent de zelfde link.
  3. De host kiest een spel.
  4. Na afloop terug naar de lobby voor een volgend spel.
  5. De host houdt een tab open.

Naar room

Host

Ga naar Room → Start room → deel QR of link. Jij kiest daarna het spel (grijs = past niet bij jullie aantal spelers).

Gast

Open de link van de host, of ga naar Room en vul de roomcode in.

Belangrijk

  • Geen account nodig — alles in de browser.
  • Host-tab dicht = verbinding weg. Host opnieuw via tab Lobby.
  • Solo: open een spel → Op dit apparaat (hotseat).
