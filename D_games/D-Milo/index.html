Uitleg

Doel — Gebruik deze app als universele basis voor allerlei games zonder dat er direct een game-scene zichtbaar hoeft te zijn.

Hub — In de play-tab kies je templates, druk je op knoppen en bouw je de structuur verder uit.

Game types — Via de tegels of via ☰ → Game types wissel je tussen avontuur, schaak, 3D, vissen, poker, memory of risk.

Karakter — Geef je poppetje een naam en kleuren. Die stijl blijft bruikbaar voor meerdere soorten games.

Modules — In de tab Modules zie je hoeveel bouwstenen en systemen actief zijn in je template.

Startscherm — Tik op Start in de onderbalk om sessions aan te maken, te laden, op te slaan en te hervatten.
